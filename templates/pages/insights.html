02 DATA & STATISTICS

데이터의 상태를 읽고
판단의 기준을 세웁니다.

데이터 품질과 통계 방법론은 분석 이전의 준비 작업이 아닙니다. 결과의 신뢰도를 결정하는 기준과 검증 절차를 실무 관점에서 설명합니다.

DATA EDITING

데이터 에디팅이란?

값을 임의로 고치는 작업이 아니라 오류 후보를 찾고, 근거가 있는 규칙과 변경 이력으로 품질을 관리하는 업무 흐름입니다.

METHOD NOTE
AI VALIDATION

규칙 기반 내검과 AI 기반 내검의 차이

확정된 기준을 반복 적용하는 규칙과 데이터에서 새로운 후보를 발견하는 AI의 역할을 구분하고, 두 방식을 함께 운영하는 구조를 설명합니다.

METHOD NOTE
DATA PROFILING

데이터 프로파일링이 필요한 이유

결측, 중복, 분포와 관계를 먼저 측정하면 막연한 정제 범위를 줄이고, 품질 규칙과 분석 계획을 실제 데이터에 맞게 세울 수 있습니다.

DATA PRACTICE
SAMPLING DESIGN

표본설계와 층화추출의 기본 개념

조사 목적과 모집단 틀을 확인한 뒤 층을 나누고 표본을 배분하는 과정이 대표성과 추정 정확도에 미치는 영향을 설명합니다.

04 APPLIED INSIGHT

분석 결과를
반복 가능한 업무로 연결합니다.

프로젝트의 결과물 자체보다 문제가 어떻게 정의되고 기술과 절차가 어떻게 연결되었는지에 집중합니다. 일회성 분석을 운영 자산으로 바꾸는 방법을 다룹니다.

DATA QUALITY PLATFORM

데이터 품질 플랫폼 구축 방법

프로파일링, 규칙 관리, 검토 업무, 실행 이력과 현황 시각화를 하나의 운영 흐름으로 연결하는 구축 관점을 정리합니다.

APPLIED NOTE
TRACEABLE ANALYTICS

재현 가능한 분석을 만드는 실행 이력

입력 데이터, 실행 조건, 코드와 모델 버전, 결과를 하나의 실행 식별자로 연결해 비교하고 설명할 수 있게 만드는 방법입니다.
