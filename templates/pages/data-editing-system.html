형태가 다른 규칙도
근거까지 읽을 수 있게.

범주형 규칙

여러 조건이 함께 나타날 때 기대되는 결과 범주를 IF–THEN으로 표현합니다. 지지도·신뢰도·향상도와 예외 행을 함께 확인합니다.

  • 조건 조합과 결과 범주 명시
  • 확률·지지도·예외 데이터 검토

연속형 규칙

수치 컬럼 사이의 관계를 A=B+C와 같은 설명 가능한 수식으로 표현합니다. 적합도·오차와 관측값 분포로 적용 가능성을 판단합니다.

  • 입력·결과 변수와 계수 공개
  • R²·RMSE·잔차와 산점도 검증

ACTUAL PRODUCT INTERFACE

작동하는 제품 화면.

분석 노드를 연결하고 범주형·연속형 규칙을 발굴한 뒤, 위반 행을 확인하는 실제 제품 흐름을 화면 단위로 살펴볼 수 있습니다.

제품 화면은 모바일 화면 너비에 맞춰 전체 구성을 한눈에 확인할 수 있습니다.

FROM RULE TO PRODUCTION

확정한 규칙을
운영 품질로 전환하는 3단계.

발굴한 후보를 최종 규칙으로 확정하고 실제 오류를 수정한 뒤, 검증된 편집 결과만 통제된 절차로 운영에 반영합니다.

RESPONSIBLE BY DESIGN

탐지를 넘어
책임 있는 운영으로.

자동 결과를 바로 확정하거나 원본에 반영하지 않습니다. 담당자가 근거와 영향을 확인할 수 있는 통제 지점을 둡니다.

01 / EXPLAIN

설명 가능한 규칙

조건과 수식, 지표와 임계값을 함께 남겨 후보가 만들어진 이유를 확인합니다.

02 / HUMAN REVIEW

전문가의 최종 판단

자동 발견 결과는 후보로 제시되며 선정·제외·확정은 담당자의 검토를 거칩니다.

03 / TRACE

재현 가능한 실행

입력 데이터, Flow 조건과 Run 결과를 연결해 같은 분석의 근거를 추적합니다.

PRODUCT DISCLOSURE

자동 발견은
최종 결정이 아닙니다.

인뎁스 IN-DEPS는 데이터 품질 검토를 지원하는 플랫폼입니다. 자동 발굴 결과는 검토 대상인 후보 규칙이며 원본 데이터를 자동 수정하지 않습니다.

  • 편집 작업은 원본과 분리된 대상에서 수행합니다.
  • 운영 반영은 생성·검증·저장·실행 절차와 담당자의 판단을 거칩니다.
  • 모델 및 규칙의 적합성은 적용 업무와 데이터 특성에 따라 별도 검증해야 합니다.
