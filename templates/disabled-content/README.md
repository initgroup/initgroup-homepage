# 비공개 보관 콘텐츠

2026-10-20 공개 메뉴와 검색 노출 정리 과정에서 인사이트 17개 페이지(허브 1개, 분류 4개, 보고서 9개, 이전 주소 사본 3개)를 이곳으로 옮겼습니다. `insights/`는 이전 파일의 보관본이며 현재 공개 URL이 아닙니다. 상대경로는 이전 위치 기준으로 보존합니다. `i18n/`에는 정리 전 한국어·영어 사전을 보관합니다.

이 디렉터리는 `static-files.json`, sitemap, 로컬 서버와 업로드 패키지에 포함하지 않습니다. 재공개하려면 콘텐츠 검토, 공개 HTML 복원, 두 언어 사전, 메뉴, 메타데이터, sitemap, 배포 목록과 `/insights/`의 410 설정을 함께 검토해야 합니다.

`assets/`에는 현재 화면이나 실행 코드에서 사용하지 않는 공개 자산 9개를 원래 경로 구조로 보관합니다. 운영 서버에서도 아래 파일을 제거합니다. Apache 설정에는 해당 이전 URL의 410 규칙을 포함했습니다.

- `assets/brand-2026/assets-manifest.json`
- `assets/brand-2026/company.webp`
- `assets/brand-2026/gaon-plaza.webp`
- `assets/brand-2026/icons.svg`
- `assets/brand-2026/research.webp`
- `assets/images/menu-heroes/insights-hero-desktop-v2.png`
- `assets/images/product/login-overview.png`
- `assets/videos/initgroup-promo-poster.jpg`
- `assets/videos/initgroup-promo-preview.mp4`

## 이전 제품 상표 자산

이전 제품 상표의 로고 12개(`assets/images/brand/`의 banner·compact, ko·en·bilingual PNG/SVG)와 사용하지 않는 영상 참고 이미지 1개(`assets/videos/`)도 이 보관 경로로 옮겼습니다. 그림에 포함된 옛 상표는 원본 기록이므로 새 상표로 이름만 바꾸지 않습니다. 원래 파일명은 운영 파일 정리와 410 URL 대조를 위해 보존하며 현재 공개 HTML이나 배포 목록에서 참조하지 않습니다. 공개 콘텐츠의 현재 표기는 인에디타원(IN-EDITAONE)입니다.
