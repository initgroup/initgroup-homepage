서비스

주요 서비스

데이터 전략부터 수집·품질, 분석과 조사까지. 전문 컨설팅과 자체 솔루션을 연결해 제공합니다.

SERVICE01

데이터 전략·통계 컨설팅

데이터 활용 전략과 통계 설계, 수요예측 및 통계 알고리즘을 업무 목적에 맞게 설계합니다.

컨설팅 범위 보기 ↗
SERVICE02

데이터 수집·통합·품질

인법스로 다양한 데이터를 수집·통합하고, 인뎁스로 품질 규칙과 검증 이력을 관리합니다.

인법스 IN-BAPS ↗인뎁스 IN-DEPS ↗
SERVICE03

AI·빅데이터·통계 분석

인법스를 통해 통계·텍스트 분석과 예측 모델링, 데이터 시각화를 업무에 연결합니다.

인법스 IN-BAPS ↗
SERVICE04

사회조사·시장조사 분석

인서베이원으로 설문 설계와 배포, 응답 수집부터 조사 결과 분석과 보고서까지 연결합니다.

인서베이원 inSurveyOne ↗

솔루션

제품 및 플랫폼

데이터 품질, 데이터 활용과 설문 운영을 위한 세 가지 제품과 플랫폼을 제공합니다.

DATA QUALITY PLATFORM

인뎁스 IN-DEPS

  • 자동 규칙 발굴
